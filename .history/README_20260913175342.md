## Tech Breakdown

This website works with PURE CSS and does not use any Javascript. Honestly I was going to use js but I am not very good at it so I wasn't comfortable with using it being of the different complexity level. 

But in short terms...

Heart Lab is built fully with html and css and every animation, every singgle toggle, and also the diagrams is fully powered with css keyframes and various selectors.

### The Css Variables for control

The entirety of the theme, pallete and even the timing of the animation are controlled through :root variables which include:

- --beat which controls the hearbeat and the ecg speed
- --paper, --card, --ink, --oxy, --deoxy all define the system of the colours used all around (personally my favourite is the background of the website (Claude taught me how to do it but I could not do it as good as it LOL)).
- --disp, --body and --mono define the typography...

So changing a single variable actually updates the WHOLE page instantly.

### Tempo system using :has()

So I implemented four heart-rate modes which include asleep, resting, running, and sprint and it uses css :has() selector, which is something I have learned recently so I am pretty surprised that it worked so amazingly.

- body:has(#r1:checked) { --beat: 1.25s }
- body:has(#r2:checked) { --beat: 0.83s }
- body:has(#r3:checked) { --beat: 0.45s }
- body:has(#r4:checked) { --beat: 0.34s }

This is the primary code for those four heart-rate modes and these lines of code are actually **Very crucial** being they **retune the entire page**, which actually includes the BPM display, animations and the ecg scroll speed without any JS.
