# PulseBeat

## What is this and why did I make this?

So this is basically a small little website I made using HTML and CSS. And a bit of help with Claude and Chatgpt. The website is about the heart which is an organ in your cardiovascular system. It talks about the heart and shows interactive visuals and various diagrams which highlight and outline parts of the heart like the ventricles, arteries, pulmonary veins and much more. I also added a few practice questions in the bottom of the website which basically just tests if you were paying attention lol. I also added a part where I created a heart which took some time so I used the website OneCompilor which made everything go much more faster in the testing part. And then I just rewrote it back here. So basically what I did was make a heart that connects to 4 various types of beats per minute, which shows a clear understanding and visual representation.
